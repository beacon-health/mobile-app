# Claude Design sync — notes

## Shape: Flutter, off-script

Beacon's components are Flutter widgets, so the design-sync converter
(`package-build.mjs`, which bundles a React library's `dist/`) and its
validator don't apply: there is no `_ds_bundle.js`, no `components/`, and no
`_ds_sync.json` anchor. The project is a tokens-and-references design system:

- `styles.css` → `tokens/tokens.css` (generated from `lib/core/theme/` via
  `design/tokens.css`) + Inter (`fonts/`) + Material Icons (Google Fonts).
- `README.md` = `.design-sync/conventions.md` (the design agent's
  instructions) + a generated index.
- `@dsCard` cards: `tokens/{colors,typography,spacing}.html` generated from
  `design/tokens.json`; `guidelines/components/*` and `guidelines/screens/*`
  showing real renders.

Build everything with:

```bash
dart run tool/build_design_bundle.dart   # add --skip-render to reuse renders
```

It renders `tool/design/render_references_test.dart` (real Inter, Material
Icons, SF Pro / Roboto for the sign-in buttons, real shadows, 2x), copies
`.design-sync/captures/`, writes `build/ds-bundle/`, and fails if the README
or a card names a token, type class, or image that doesn't exist.

## Re-sync

1. Rebuild the bundle (above) and look over the cards — the built-in browser
   can't open local files, so render them with Quick Look:
   `qlmanage -t -s 1400 -o <dir> build/ds-bundle/**/*.html`.
2. Upload to the pinned project (`projectId` in `config.json`) through the
   atomic path: sentinel `_ds_needs_recompile` first, then every file in
   `build/ds-bundle/`, then delete remote files under `tokens/`, `fonts/`,
   `guidelines/` that the bundle no longer has, then re-write the sentinel.
   With no anchor, every sync re-uploads everything; the bundle is ~5 MB.

## Known quirks

- The login render shows a box after "Select a language": the string ends in
  🌐 and the test engine has no emoji font. Devices render it. The card says so.
- `.claude/launch.json` static servers don't work for previewing: python's
  `http.server` never binds under the app's launcher, and the built-in browser
  can't open servers Claude starts anyway. Use Quick Look.

## Re-sync risks

- **Device captures go stale silently.** `.design-sync/captures/` (Home and
  Map, taken 2026-09-28 on an iPhone 17 Pro simulator and a Pixel 10 Pro
  emulator) can't be regenerated by the tool — Home and Map need Google Maps
  and Supabase. Re-capture them when those screens change.
- **Reference renders depend on the machine:** SF Pro from
  `/System/Library/Fonts/SFNS.ttf` and Roboto from the Flutter SDK's
  `material_fonts` cache. Without them the sign-in buttons render in a
  fallback font (the renderer skips missing files silently).
- **Material Icons load from Google Fonts at runtime** (remote `@import` in
  `styles.css`), not from the bundle.
- **`conventions.md` is hand-written.** The builder verifies every token and
  class it names, but not that its prose still matches the app — reread it
  when components change.
